= 刪除儲存後端
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
刪除儲存設備後端。使用此行動從系統中移除所有關聯的 backendConfig 和 backendNode 資源。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/storageBackends/{storageBackend_id}`#



[[usage-notes]]
== 使用注意事項

移除指定的儲存後端 API 資源。

*副作用*

* 與儲存後端相關的所有 backendConfig 資源均被移除。
* 與儲存後端相關的所有 backendNode 資源均被移除。
* 儲存後端可能會被移除。




[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| storageBackend_id | 字串 | 路徑 | True  a| 
要列出的 storageBackend 集合的 ID

|===
