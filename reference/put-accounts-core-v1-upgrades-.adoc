= 修改升級
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/upgrades/{upgrade_id}`#

將整個儲存的資源替換為提供的 JSON 請求主體，同時保留使用者不可修改的鍵值。

*副作用*

* 升級是根據所需狀態進行排程或執行。




[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| upgrade_id | 字串 | 路徑 | True  a| 
要列出的升級集合 ID

|===


[[request-body]]
== 請求本文

將整個儲存的資源替換為提供的 JSON 請求主體，同時保留使用者不可修改的鍵值。

*副作用*

* 升級是根據所需狀態進行排程或執行。


[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-upgrade"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"




| ID | 字串 | 錯誤  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| componentName | 字串 | 錯誤  a| 
包含可升級軟體類型名稱的 JSON 字串。已定義的值包括：

* "acc"
* "acs"
* "Trident"
* "kubernetes"




| componentInstance | 字串 | 錯誤  a| 
包含可升級元件 URI 的 JSON 字串。已定義的值包括：

* 最短長度：3
* 最大長度：4095




| componentID | 字串 | 錯誤  a| 
包含可升級元件的全域唯一識別碼的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| upgradeVersion | 字串 | 錯誤  a| 
包含可升級到的軟體映像檔案的 SemVer 的 JSON 字串。已定義的值包括：

* 符合 SemVer 模式




| currentVersion | 字串 | 錯誤  a| 
包含待升級實體目前 SemVer 的 JSON 字串。已定義的值包括：

* 符合 SemVer 模式




| 相依性 | 陣列［string］ | 錯誤  a| 
JSON 字串的 JSON 陣列，每個字串包含一個升級的 UUID，該升級必須在目前升級之前完成。用於確定哪些升級將作為先決條件執行以及執行順序。已定義的值包括：

* 符合 Astra 識別符架構




| 狀態 | 字串 | 錯誤  a| 
JSON 字串，包含指示升級運作狀態的值。如果啟用自動升級，升級將以「scheduled」狀態開始。否則，升級將以「proposed」狀態開始。定義的值為：

* 「unavailable」- 目前無法進行升級
* 「proposed」- 升級已提出，但在獲得核准之前不會自動執行
* 「已排程」- 升級已獲核准，但由於相依性、時間範圍或可用資源而尚未準備好安裝
* "running" - 升級正在進行中
* 「complete」—升級已完成
* 「failed」—升級未完成




| stateDesired | 字串 | 錯誤  a| 
包含「state」所需狀態值的 JSON 字串。只有當使用者可以直接要求變更資源狀態時，才會包含此欄位。已定義的值包括：

* 「proposed」——該升級未經批准，不得執行
* 「已安排」- 升級已獲批准，必須在指定的時間窗口內執行
* 「running」- 無論時間視窗如何，升級都必須立即執行




| stateDetails | 陣列[link:#type_astra_stateDetail["type_astra_stateDetail"]] | 錯誤  a| 
JSON 物件的 JSON 陣列，其中列出有關目前「狀態」的其他詳細資料。如果沒有可用的詳細資料，此陣列將為空白。

* 最低項目數：0




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra Metadata Schema。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===

[%collapsible]

  "version": "1.1",
  "stateDesired": "running"
}
----
====
