= Astra API (ACC) 命名空間端點
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
檢視屬於叢集的命名空間。這些端點是唯讀的。

Namespace API 提供對命名空間資源的唯讀存取，以便描述與給定叢集相關聯的命名空間。
