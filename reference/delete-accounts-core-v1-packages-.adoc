= 刪除套件
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
刪除套件，從系統中移除指定的 Package API 資源。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/packages/{package_id}`#



[[usage-notes]]
== 使用注意事項

移除指定的 Package API 資源。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| package_id | 字串 | 路徑 | True  a| 
要列出的套件集合 ID

|===

== 回應

[source]
----
Status: 204, Indicates if the package resource was deleted.
