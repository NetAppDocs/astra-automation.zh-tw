= 為應用程式建立新的執行掛鉤
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
為應用程式建立一個新的執行鉤子，以指定自動化流程或整合所需的值。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/executionHooks`#



[[usage-notes]]
== 使用注意事項

指示要建立的 Execution Hook API 資源的期望值。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| app_id | 字串 | 路徑 | True  a| 
包含應用程式資源的 ID

|===


[[request-body]]
== 請求本文

指示要建立的 Execution Hook API 資源的期望值。

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-executionHook"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"
* "1.3"




| 姓名 | 字串 | True  a| 
包含使用者指定資源名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63 名稱在所有執行掛鉤資源中必須是唯一的。




| hookType | 字串 | True  a| 
定義勾點類型的 JSON 字串。定義的值包括：

* "netapp" - NetApp 提供的執行鉤子。
* 「custom」- 與特定的應用程式 ID 綁定。具有 hookType 「netapp」的執行鉤子資源為唯讀。




| matchingCriteria | 陣列[link:#matchingCriteria["matchingCriteria"]] | 錯誤  a| 
描述執行鉤子匹配條件的 JSON 物件 JSON 陣列。當指定多個 matchingCriteria 時，會對條件套用邏輯 AND。定義的值為：

* 最少項目數：0
* 最多項目數：10




| 動作 | 字串 | True  a| 
JSON 字串，指示在符合條件的情況下，執行掛鉤將執行哪個動作。定義的值為：

* 「Snapshot」
* 「備份」
* 「還原」
* 「容錯移轉」




| 階段 | 字串 | True  a| 
JSON 字串，指示掛鉤將在動作的哪個階段執行。已定義的值包括：

* "pre" - 執行鉤子將在指定操作之前執行。
* "post" - 執行掛鉤將在指定動作之後執行。動作 "snapshot" 的值為 "pre" 和 "post"。動作 "backup" 的值為 "pre" 和 "post"。動作 "restore" 的值為 "post"。動作 "failover" 的值為 "post"。




| hookSourceID | 字串 | True  a| 
包含透過此執行掛鉤執行的掛鉤來源 ID 的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 引數 | 陣列［string］ | 錯誤  a| 
來源引數的 JSON 字串 JSON 陣列。定義的值為：

* 最少項目數：0
* 項目上限：16
* 最短長度：0
* 最大長度：127




| appID | 字串 | True  a| 
包含此鉤子所關聯應用程式 ID 的 JSON 字串。本質上，其他匹配條件（如果已設定）。已定義的值包括：

* 符合 Astra 識別符架構




| 已啟用 | 字串 | 錯誤  a| 
指示執行掛鉤是否已啟用的 JSON 字串。已定義的值包括：

* "true" - 執行鉤子已啟用，並將按指定方式執行。
* 「false」－執行鉤子已停用，永遠無法運作。預設值為「true」。




| 描述 | 字串 | 錯誤  a| 
包含使用者指定的 hook 來源描述的 JSON 字串。已定義的值包括：

* 最短長度：0
* 最大長度：511




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例請求
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-executionHook",
  "version": "1.3",
  "name": "Payroll",
  "hookType": "custom",
  "action": "snapshot",
  "stage": "pre",
  "hookSourceID": "50e89023-ba84-435d-bb47-1833f4c250ff",
  "arguments": [
    "freeze"
  ],
  "appID": "7be5ae7c-151d-4230-ac39-ac1d0b33c2a9",
  "enabled": "true",
  "description": "Payroll production hook"
}
----
====
