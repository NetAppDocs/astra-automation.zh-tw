= 修改儲存後端
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/storageBackends/{storageBackend_id}`#

將整個儲存的資源替換為提供的 JSON 請求主體，同時保留使用者不可修改的鍵值。

*副作用*

* 指定組態版本會導致套用儲存後端類型專屬的組態變更，其中可能包括儲存後端的初始安裝。
* 指定組態版本可能會導致 storageClass 資源的新增、修改或刪除。




[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| storageBackend_id | 字串 | 路徑 | True  a| 
要列出的 storageBackend 集合的 ID

|===


[[request-body]]
== 請求本文

將整個儲存的資源替換為提供的 JSON 請求主體，同時保留使用者不可修改的鍵值。

*副作用*

* 指定組態版本會導致套用儲存後端類型專屬的組態變更，其中可能包括儲存後端的初始安裝。
* 指定組態版本可能會導致 storageClass 資源的新增、修改或刪除。


[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-storageBackend"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"
* "1.3"




| ID | 字串 | 錯誤  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| backendName | 字串 | 錯誤  a| 
包含使用者指定的儲存後端名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63




| backendType | 字串 | 錯誤  a| 
包含一個值的 JSON 字串，該值指示所表示的儲存後端類型。已定義的值包括：

* 「ontap」－儲存後端代表一個 NetApp ONTAP 系統
* 列舉：["ontap"]
* 例如：ONTAP




| backendVersion | 字串 | 錯誤  a| 
包含一個值的 JSON 字串，該值指示所代表的儲存後端版本。已定義的值包括：

* 最短長度：1
* 最大長度：63




| backendCredentialsName | 字串 | 錯誤  a| 
JSON 字串包含一個值，指示用於儲存後端的一個或多個認證資源的名稱。允許認證輪替，其中多個認證物件具有相同的名稱。定義的值為：

* 最短長度：1
* 最大長度：63




| configVersion | 字串 | 錯誤  a| 
包含值的 JSON 字串，該值指示儲存後端要使用的作用中組態。已定義的值包括：

* 最短長度：1
* 最大長度：63




| 狀態 | 字串 | 錯誤  a| 
包含指示儲存後端運作狀態值的 JSON 字串。已定義的值包括：

* 「已發現」- 已從託管叢集中發現儲存後端
* 「running」- 儲存後端運作正常
* 「未知」- 無法判斷儲存後端的狀態
* 「失敗」- 儲存後端處於無法使用的狀態




| stateDesired | 字串 | 錯誤  a| 
包含一個值的 JSON 字串，該值指示儲存後端所需的運作狀態。已定義的值包括：

* 「running」- 儲存後端將處於正常運作狀態




| stateUnready | 陣列［string］ | 錯誤  a| 
JSON 字串的 JSON 陣列，每個字串分別指示儲存後端無法轉換到「執行中」狀態、已轉換為「失敗」或「未知」狀態，以及 / 或存在轉換到「失敗」狀態風險的原因。已定義的值包括：

* 最短長度：1
* 最大長度：127




| managedState | 字串 | 錯誤  a| 
JSON 字串包含指示儲存後端管理狀態的值。定義的值為：

* 「pending」- 儲存後端已排程進行探索或新增
* 「未託管」 - 儲存後端處於「已發現」狀態，未受管理，且符合管理資格
* 「已託管」 - 儲存後端處於「執行中」或「未知」狀態，並且正在管理中




| managedStateUnready | 陣列［string］ | 錯誤  a| 
JSON 字串的 JSON 陣列，每個字串表示儲存後端不符合管理條件的原因。已定義的值包括：

* 最短長度：1
* 最大長度：127




| healthState | 字串 | 錯誤  a| 
JSON 字串，包含指示儲存後端健全狀況的值。定義的值包括：

* 「不確定」- 無法判斷資源的健全狀況 （例如，由於缺乏連線能力）
* 「normal」- 資源沒有已知問題，可依據介面規格提供服務
* 「警告」- 該資源有已知問題，但這並不妨礙其依照介面規範提供服務
* 「critical」- 此資源有已知問題，導致其無法依照介面規格提供服務




| healthStateUnready | 陣列［string］ | 錯誤  a| 
JSON 字串的 JSON 陣列，每個字串表示儲存後端不處於正常健全狀態的原因。定義的值為：

* 最短長度：1
* 最大長度：127




| protectionState | 字串 | 錯誤  a| 
包含指示儲存後端保護狀態值的 JSON 字串。對於 ONTAP 為 "unknown"。已定義的值包括：

* 「受保護」 - 儲存後端已定義保護原則，並且符合該原則
* 「部分」- 儲存後端已定義保護原則，但不符合該原則
* 「none」- 儲存後端未受保護
* 「未知」- 無法判斷儲存後端保護原則一致性
* 列舉：［「protected」「partial」「none」「unknown」］
* 範例：受保護




| protectionStateUnready | 陣列［string］ | 錯誤  a| 
JSON 字串的 JSON 陣列,每個字串表示保護原則不符合規範的原因。定義的值為:

* 最短長度：1
* 最大長度：127




| ONTAP | link:#ontap["ONTAP"] | 錯誤  a| 
包含與 ONTAP 叢集相關之特定資訊的 JSON 物件。

* additionalProperties：false




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。
