= 刪除群組
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}`#

移除指定的 Group API 資源。

*副作用*

* 與該群組相關的以下資源會被刪除：
* 參照該群組的角色繫結




== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 群組 ID | 字串 | 路徑 | True  a| 
要列出的群組集合 ID

|===
