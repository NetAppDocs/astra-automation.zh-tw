= 建立新訂閱
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
建立新訂閱，並指定訂閱 API 資源的所需值。使用此功能可以啟動具有自訂的設定的訂閱，以滿足您的特定需求。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/subscriptions`#



[[usage-notes]]
== 使用注意事項

指示要建立的 Subscription API 資源的期望值。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}


|===


[[request-body]]
== 請求本文

指示要建立的 Subscription API 資源的期望值。

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-subscription"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"




| customerProfileID | 字串 | 錯誤  a| 
包含客戶資料 ID 的 JSON 字串 http://authorize.net["Authorize.net"]（由 UI 呼叫）在試用期內未設定。如果未設定，則在讀取操作期間傳回空字串。已定義的值包括：

* 最短長度：0
* 最大長度：63




| paymentFirstName | 字串 | 錯誤  a| 
包含使用者指定的用於支付帳單的完整名字的 JSON 字串。僅在重新計費訂閱時指定。已定義的值包括：

* 最短長度：1
* 最大長度：63




| paymentLastName | 字串 | 錯誤  a| 
包含使用者指定的用於付款帳單的完整姓氏的 JSON 字串。僅在重新計費訂閱時指定。定義的值為：

* 最短長度：1
* 最大長度：63




| paymentAddress | link:#paymentAddress["paymentAddress"] | 錯誤  a| 
包含一組 JSON 字串的 JSON 物件，用於指定帳單地址。僅在重新計費訂閱時指定。如果此金鑰存在，則包含的所有六個 JSON 字串都將存在。如果使用者未提供任何資訊，則該字串為空白。



| paymentProfileID | 字串 | 錯誤  a| 
包含由使用者介面呼叫的 http://Authorize.net["Authorize.net"]支付設定檔 ID 的 JSON 字串，未設定為試用期。如果未設定，則在讀取操作期間傳回空字串。已定義的值包括：

* 最短長度：0
* 最大長度：63




| paymentExpiry | 字串 | 錯誤  a| 
包含時間戳記的 JSON 字串，指示付款方式的到期時間。此資訊來自 authorize.net](http://authorize.net[]，並由使用者介面設定。已定義的值包括：

* 符合 ISO-8601 日期時間架構。試用條款不會傳回此欄位。




| 市集 | 字串 | 錯誤  a| 
JSON 字串，用於指示帳戶的市場，付款資訊將在該市場上記錄。定義值：

* "netapp"
* "azure"
* "aws"
* "gcp"




| 條款 | 字串 | True  a| 
表示帳戶目前層級的 JSON 字串。定義的值包括：

* 「trial」
* 「paid」




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例請求
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-subscription",
  "version": "1.2",
  "terms": "trial"
}
----
====

[[paymentAddress]]

paymentAddress

包含一組 JSON 字串的 JSON 物件，用於指定帳單地址。僅在重新計費訂閱時指定。如果此金鑰存在，則包含的所有六個 JSON 字串都將存在。如果使用者未提供任何資訊，則該字串為空白。

|===

包含與郵政地址關聯的國家/地區名稱或國家/地區代碼的 JSON 字串，如 ISO 3166 Alpha-2 中所指定。定義的值為：

* 最大長度：63

* 最短長度：0
* 最大長度：63




| streetAddress2 | 字串 | 錯誤  a| 
包含選用輔助街道地址資訊、郵政信箱等的 JSON 字串。已定義的值包括：

* 最短長度：0
* 最大長度：63
