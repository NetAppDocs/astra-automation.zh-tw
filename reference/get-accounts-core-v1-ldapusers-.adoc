= 擷取 LDAP 使用者
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
檢索 LDAP 使用者，提供儲存的資源組態，用於使用者管理和驗證任務。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/ldapUsers/{ldapUser_id}`#



[[usage-notes]]
== 使用注意事項

傳回代表已儲存 LDAP 資源的 JSON 物件。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| ldapUser_id | 字串 | 路徑 | True  a| 
要列出的 ldapUser 集合的 ID

|===


[[response]]
== 回應

[source]
----
Status: 200, Returns a JSON object representing the stored LDAP resource.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-ldapUser"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 電子郵件 | 字串 | 錯誤  a| 
表示 LDAP 使用者電子郵件的 JSON 字串。已定義的值包括：

* 最短長度：3
* 最大長度：63




| firstName | 字串 | 錯誤  a| 
代表 LDAP 使用者名字的 JSON 字串。定義的值為：

* 最短長度：1
* 最大長度：63




| lastName | 字串 | 錯誤  a| 
表示 LDAP 使用者姓氏的 JSON 字串。定義的值包括：

* 最短長度：1
* 最大長度：63




| cn | 字串 | 錯誤  a| 
表示 LDAP 群組名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63




| dn | 字串 | 錯誤  a| 
表示 LDAP 群組專有名稱的 JSON 字串。已定義的值包括：

* 符合 RFC 4514 標準




| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構


|===
