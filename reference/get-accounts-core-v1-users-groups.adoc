= 列出使用者的群組
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
檢索與使用者關聯的群組列表，提供詳細群組資訊的存取，以便管理或分析。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/users/{user_id}/groups`#



[[usage-notes]]
== 使用注意事項

傳回集合中所有符合資源的 JSON 陣列。如果在請求中指定了個別欄位，則項目 JSON 陣列將按指定順序包含每個相符資源所請求的欄位。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| user_id | 字串 | 路徑 | True  a| 
包含使用者資源的 ID



| 包括 | 字串 | 查詢 | 錯誤  a| 
指示列出集合時應傳回哪些欄位。

URL 範例：「include=id」、「include=id,name」

| 限制 | 字串 | 查詢 | 錯誤  a| 
表示列出集合時要傳回的資源數量上限。

URL 範例：「limit=2」

OpenAPI 範例：「2」



| 篩選器 | 字串 | 查詢 | 錯誤  a| 
指示在列出集合時，為了傳回資源而應符合哪些欄位。

支援的運算子包括：

* eq - 等式

| 數 | 字串 | 查詢 | 錯誤  a|

| 類型 | 字串 | True  a|

| 姓名 | 字串 | True  a| 
群組資源的名稱。如果在建立時未指定，則該值將設定為

* 如果在 authID 中找到，則為第一個通用名稱（CN）相對專有名稱（RDN），
* 否則為 authID。如果在更新時未指定，則該值將保留而不進行修改。定義的值為：
* 最短長度：1
* 最大長度：2048




| authProvider | 字串 | True  a| 
群組資源的驗證提供者。定義的值為：

* "ldap"




| authID | 字串 | True  a| 
LDAP 群組的辨別名稱（DN）。定義的值為：

* 最短長度：1
* 最大長度：2048
