= 列出所有授權
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
擷取集合中的所有授權，並傳回相符資源的 JSON 陣列。您可以在要求中指定個別欄位，以自訂每個授權傳回的資訊。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/licenses`#



[[usage-notes]]
== 使用注意事項

傳回集合中所有符合資源的 JSON 陣列。如果在請求中指定了個別欄位，則項目 JSON 陣列將按指定順序包含每個相符資源所請求的欄位。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 包括 | 字串 | 查詢 | 錯誤  a| 
指示列出集合時應傳回哪些欄位。

URL 範例：「include=id」、「include=id,name」

OpenAPI 範例："id"

* 範例：id、product




| 限制 | 字串 | 查詢 | 錯誤  a| 
表示列出集合時要傳回的資源數量上限。

URL 範例：「limit=2」

OpenAPI 範例：「2」



| 篩選器 | 字串 | 查詢 | 錯誤  a| 
指示在列出集合時，為了傳回資源而應符合哪些欄位。

支援的運算子包括：

* eq - 等式
* lt/gt - 小於/大於
* lte/gte - 小於或等於/大於或等於


URL 範例：「filter=field%20eq%20%27value%27」

OpenAPI 範例："field eq 'value'"

|===

| 分配 | 字串 | 錯誤  a| 
包含 ID 的 JSON 字串，指示授權分配給哪個對象。僅在分配授權時存在。對於 Astra Control Center 授權，此欄位必須填入帳戶 ID，並且必須與 POST URI 中指定的帳戶 ID 相符。已定義的值包括：

* 符合 Astra 識別符架構




| hostID | 字串 | 錯誤  a| 
包含授權綁定的主機識別碼的 JSON 字串。僅當授權鎖定到主機時才存在。已定義的值包括：

* 最短長度：1
* 最大長度：63




| deviceCredentialID | 字串 | 錯誤  a| 
包含與 Credential API 關聯的 deviceCredential 識別碼的 JSON 字串。僅適用於 Astra Data Store 授權。定義的值為：

* 符合 Astra 識別符架構




| isEvaluation | 字串 | True  a| 
JSON 字串，用於指示授權是否為評估授權。定義的值為：

* "true"
* "false"




| licenseProtocol | 字串 | True  a| 
包含從授權中擷取的授權通訊協定的 JSON 字串。定義的值包括：

* 字串內容未經架構驗證




| licenseText | 字串 | True  a| 
JSON 字串，包含從 NetApp 授權系統取得的授權 JSON 的 base64 編碼表示。必須以原始位元組層級順序提供，以便進行簽章驗證。定義的值為：

* 符合 base64 編碼資料架構




| validFromTimestamp | 字串 | True  a| 
包含時間戳記的 JSON 字串，指示授權何時生效。已定義的值包括：

* 符合 ISO-8601 日期時間架構




| validUntilTimestamp | 字串 | True  a| 
包含時間戳記的 JSON 字串，指示授權何時不再有效。定義的值為：

* 符合 ISO-8601 日期時間架構

包含從授權中擷取的產品字串的 JSON 字串。已定義的值為：

* 字串內容未經架構驗證

* 字串內容未經架構驗證

* 字串內容未經架構驗證
