= Astra API（ACC）功能端點
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
透過讀取功能標誌來檢查哪些 Astra Control 功能已啟用或已停用。

功能 API 提供對功能標誌資源的唯讀存取，以決定系統中啟用或停用了哪些功能。
