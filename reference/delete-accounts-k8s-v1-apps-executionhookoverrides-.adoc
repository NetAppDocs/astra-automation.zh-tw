= 刪除執行掛鉤覆寫資源
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
刪除執行掛鉤置換資源。使用此功能可移除應用程式中執行掛鉤的自訂組態。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/executionHookOverrides/{executionHookOverride_id}`#



[[usage-notes]]
== 使用注意事項

移除指定的 Execution Hook Override API 資源。

*副作用*

* 當刪除新的執行鉤子覆蓋時，如果其啟用值為 "false"，則適用於指定應用程式的任何 hookType 值為 "netapp" 的執行鉤子都將啟用。



CAUTION: 此操作已棄用。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| app_id | 字串 | 路徑 | True  a| 
包含應用程式資源的 ID



| executionHookOverride_id | 字串 | 路徑 | True  a| 
要列出的 executionHookOverride 集合的 ID

|===
