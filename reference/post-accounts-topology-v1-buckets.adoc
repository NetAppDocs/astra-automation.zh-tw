= 建立新的儲存區
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
在 Astra API 中建立新的儲存桶，指定要建立的儲存桶 API 資源所需的值。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/buckets`#



[[usage-notes]]
== 使用注意事項

指示要建立的 Bucket API 資源的期望值。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}


|===


[[request-body]]
== 請求本文

指示要建立的 Bucket API 資源的期望值。

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-bucket"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"




| 姓名 | 字串 | 錯誤  a| 
包含使用者為儲存貯體指定的名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：256




| credentialID | 字串 | True  a| 
包含用於存取儲存貯體的憑證識別碼的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 供應商 | 字串 | True  a| 
JSON 字串，指示可用於存取儲存桶的儲存桶協定。已定義的值包括：

* "ontap-s3"
* "storagegrid-s3"
* "generic-s3"
* "gcp"
* "azure"
* "aws"




| bucketParameters | link:#bucketParameters["bucketParameters"] | True  a| 
此 JSON 物件提供存取儲存貯體所需的特定於儲存貯體提供者的資訊。此儲存貯體中的具體值因提供者而異。



| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例請求
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-bucket",
  "version": "1.2",
  "name": "Test Bucket",
  "credentialID": "d5b3854c-38de-42c6-9269-b5c052aba76f",
  "provider": "gcp",
  "bucketParameters": {
    "gcp": {
      "bucketName": "bucketName"
    }
  }
}
----
====


[[response]]
== 回應

[source]
----
Status: 201, Returns the newly created bucket resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-bucket"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
包含使用者為儲存貯體指定的名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：256




| credentialID | 字串 | True  a| 
包含用於存取儲存貯體的憑證識別碼的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 狀態 | 字串 | True  a| 
包含指示儲存貯體運作狀態的值的 JSON 字串。已定義的值包括：

* 「pending」- 儲存貯體已排程進行探索
* 「available」- 儲存貯體可供使用
* 「failed」- 儲存區處於永久故障狀態
* 「已移除」- 此儲存桶目前無法存取
* 「未知」- 無法判斷儲存貯體狀態




| stateDetails | 陣列[link:#type_astra_stateDetail["type_astra_stateDetail"]] | True  a| 
JSON 物件的 JSON 陣列，其中列出了有關「狀態」為何轉換為「已移除」或「失敗」的其他詳細資訊。如果沒有可用的詳細資訊，此陣列將為空白。

* 最少項目數：0




| retentionTime | 數字 | 錯誤  a| 
表示此儲存桶中檔案保留時間的秒數。定義的值為：

* -1（不支援的儲存貯體）
* 0 （無已知保留原則）
* 
+
[quote]
____
0 （已知保留原則）

____

* "storagegrid-s3"
* "generic-s3"
* "gcp"
* "azure"
