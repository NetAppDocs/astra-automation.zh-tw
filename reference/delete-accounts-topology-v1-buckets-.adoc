= 刪除儲存區
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/buckets/{bucket_id}`#

移除指定的 Bucket API 資源。

*副作用*

* 內部資料結構已清理。




== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| bucket_id | 字串 | 路徑 | True  a| 
要列出的儲存貯體集合 ID

|===

Status: 204, Indicates if the bucket resource was deleted.
