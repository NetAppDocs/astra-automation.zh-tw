= 修改執行掛鉤覆寫資源
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/executionHookOverrides/{executionHookOverride_id}`#

將整個儲存的資源替換為提供的 JSON 請求主體，同時保留使用者不可修改的鍵值。

*副作用*

* 如果在替換操作期間將 enabled 的值從 "true" 變更為 "false"，則適用於指定應用程式且 hookType 值為 "netapp" 的任何執行鉤子都將停用。
* 如果在取代操作期間 enabled 的值從 "false" 變更為 "true"，則適用於指定應用程式且 hookType 值為 "netapp" 的任何執行鉤子都會啟用。



CAUTION: 此操作已棄用。

[[request-body]]
== 請求本文

將整個儲存的資源替換為提供的 JSON 請求主體，同時保留使用者不可修改的鍵值。

*副作用*

* 如果在替換操作期間將 enabled 的值從 "true" 變更為 "false"，則適用於指定應用程式且 hookType 值為 "netapp" 的任何執行鉤子都將停用。
* 如果在取代操作期間 enabled 的值從 "false" 變更為 "true"，則適用於指定應用程式且 hookType 值為 "netapp" 的任何執行鉤子都會啟用。


[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-executionHookOverride"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | 錯誤  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| executionHookID | 字串 | 錯誤  a| 
包含執行掛鉤 ID 的 JSON 字串。已定義的值包括：

* 符合 Astra 識別碼架構，僅允許 hookType 值為「netapp」的執行鉤子資源的 executionHookID。




| 已啟用 | 字串 | 錯誤  a| 
指示是否為指定應用程式啟用執行鉤子的 JSON 字串。已定義的值包括：

* 「true」- 執行掛鉤已啟用，並將按指定順序執行
* 「false」- 執行掛鉤已停用，無法執行




| appID | 字串 | 錯誤  a| 
包含與此覆寫操作關聯的應用程式 ID 的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===

[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-executionHookOverride",
  "version": "1.0",
  "enabled": "false"
}
----
====
