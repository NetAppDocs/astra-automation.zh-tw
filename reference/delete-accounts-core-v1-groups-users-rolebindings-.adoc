= 刪除群組中使用者的角色繫結
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}/users/{user_id}/roleBindings/{roleBinding_id}`#

移除指定的角色繫結 API 資源。

*副作用*

* 刪除與使用者關聯的最後一個角色繫結（authProvider 為「local」或「cloud-central」（非 ldap））會觸發刪除該使用者。




== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 群組 ID | 字串 | 路徑 | True  a| 
包含群組資源的 ID



| user_id | 字串 | 路徑 | True  a| 
包含使用者資源的 ID



| roleBinding_id | 字串 | 路徑 | True  a| 
要列出的 roleBinding 集合的 ID

|===
