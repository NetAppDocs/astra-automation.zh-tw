= 刪除應用程式備份
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/appBackups/{appBackup_id}`#

移除指定的 Application Backup API 資源。正在進行的備份將被取消，然後刪除。

*副作用*

* 如果備份完成，備份資料將被刪除。




[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| appBackup_id | 字串 | 路徑 | True  a| 
要列出的 appBackup 集合的 ID

|===


[[response]]
== 回應

[source]
----
Status: 204, Indicates if the appBackup resource was deleted.
----
