= 建立新授權
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
建立新授權，並指定授權 API 資源所需的值。使用此端點可有效管理您環境中的授權需求。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/licenses`#



[[usage-notes]]
== 使用注意事項

指示要建立的 License API 資源所需的值。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}


|===


[[request-body]]
== 請求本文

指示要建立的 License API 資源所需的值。

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-license"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| 分配 | 字串 | 錯誤  a| 
包含 ID 的 JSON 字串，指示授權分配給哪個對象。僅在分配授權時存在。對於 Astra Control Center 授權，此欄位必須填入帳戶 ID，並且必須與 POST URI 中指定的帳戶 ID 相符。已定義的值包括：

* 符合 Astra 識別符架構




| deviceCredentialID | 字串 | 錯誤  a| 
包含與 Credential API 關聯的 deviceCredential 識別碼的 JSON 字串。僅適用於 Astra Data Store 授權。定義的值為：

* 符合 Astra 識別符架構




| licenseText | 字串 | True  a| 
JSON 字串，包含從 NetApp 授權系統取得的授權 JSON 的 base64 編碼表示。必須以原始位元組層級順序提供，以便進行簽章驗證。定義的值為：

* 符合 base64 編碼資料架構




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例請求
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-license",
  "version": "1.0",
  "allocation": "4185d09b-6687-4801-a832-c005a9d94f41",
  "licenseText": "ewogICAic3RhdHVzUmVzcCI6ewogMTYwNzAwIgp9"
}
----
====

== 回應

[source]
----
Status: 201, Returns the newly created license resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-license"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 分配 | 字串 | 錯誤  a| 
包含 ID 的 JSON 字串，指示授權分配給哪個對象。僅在分配授權時存在。對於 Astra Control Center 授權，此欄位必須填入帳戶 ID，並且必須與 POST URI 中指定的帳戶 ID 相符。已定義的值包括：

* 符合 Astra 識別符架構




| hostID | 字串 | 錯誤  a| 
包含授權綁定的主機識別碼的 JSON 字串。僅當授權鎖定到主機時才存在。已定義的值包括：

* 最短長度：1
* 最大長度：63




| deviceCredentialID | 字串 | 錯誤  a| 
包含與 Credential API 關聯的 deviceCredential 識別碼的 JSON 字串。僅適用於 Astra Data Store 授權。定義的值為：

* 符合 Astra 識別符架構




| isEvaluation | 字串 | True  a| 
JSON 字串，用於指示授權是否為評估授權。定義的值為：

* "true"
* "false"




| licenseProtocol | 字串 | True  a| 
包含從授權中擷取的授權通訊協定的 JSON 字串。定義的值包括：

* 字串內容未經架構驗證




| licenseText | 字串 | True  a| 
JSON 字串，包含從 NetApp 授權系統取得的授權 JSON 的 base64 編碼表示。必須以原始位元組層級順序提供，以便進行簽章驗證。定義的值為：

* 符合 base64 編碼資料架構




| validFromTimestamp | 字串 | True  a| 
包含時間戳記的 JSON 字串，指示授權何時生效。已定義的值包括：

* 符合 ISO-8601 日期時間架構




| validUntilTimestamp | 字串 | True  a| 
包含時間戳記的 JSON 字串，指示授權何時不再有效。定義的值為：

* 符合 ISO-8601 日期時間架構




| 產品 | 字串 | True  a| 
包含從授權中擷取的產品字串的 JSON 字串。已定義的值為：

* 字串內容未經架構驗證




| productVersion | 字串 | True  a| 
包含從授權中擷取的版本字串的 JSON 字串。已定義的值包括：

* 字串內容未經架構驗證




| 產品 SN | 字串 | True  a| 
包含從授權中擷取的序號字串的 JSON 字串。定義的值為：

* 字串內容未經架構驗證




| 功能 | 字串 | True  a| 
包含從授權中擷取的套件值的 JSON 字串。已定義的值包括：

* 字串內容未經架構驗證




| 容量 | 字串 | True  a| 
包含從授權中擷取之容量的 JSON 字串。



| capacity2 | 字串 | True  a| 
包含從授權中擷取之次要容量的 JSON 字串。



| 附加元件 | 陣列[link:#addons["附加元件"]] | 錯誤  a| 
包含授權附加元件清單的 JSON 物件 JSON 陣列。附加元件是指授權在未來某個潛在日期發生的變更。



| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。
