= 擷取執行掛鉤覆寫資源
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/executionHookOverrides/{executionHookOverride_id}`#

在 JSON 回應內文中傳回已儲存的 Execution Hook Override API 資源。


CAUTION: 此操作已棄用。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| app_id | 字串 | 路徑 | True  a| 
包含應用程式資源的 ID



| executionHookOverride_id | 字串 | 路徑 | True  a| 
要列出的 executionHookOverride 集合的 ID

|===


[[response]]
== 回應

[source]
----
Status: 200, Returns the stored Execution Hook Override API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-executionHookOverride"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| executionHookID | 字串 | True  a| 
包含執行掛鉤 ID 的 JSON 字串。已定義的值包括：

* 符合 Astra 識別碼架構，僅允許 hookType 值為「netapp」的執行鉤子資源的 executionHookID。




| 已啟用 | 字串 | True  a| 
指示是否為指定應用程式啟用執行鉤子的 JSON 字串。已定義的值包括：

* 「true」- 執行掛鉤已啟用，並將按指定順序執行
* 「false」- 執行掛鉤已停用，無法執行




| appID | 字串 | True  a| 
包含與此覆寫操作關聯的應用程式 ID 的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例回應
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-executionHookOverride",
  "version": "1.0",
  "id": "c11af802-5e53-5897-8cd9-2de730494be3",
  "executionHookID": "eb863cc6-0d9a-454d-8ef7-81b7cac91929",
  "enabled": "false",
  "appID": "4b43c2f7-bffa-4f60-b595-d98a05b64bc9",
  "metadata": {
    "labels": [],
    "creationTimestamp": "2022-10-06T20:58:16.305662Z",
    "modificationTimestamp": "2022-10-06T20:58:16.305662Z",
    "createdBy": "8f84cf09-8036-51e4-b579-bd30cb07b269"
  }
}
----
====
