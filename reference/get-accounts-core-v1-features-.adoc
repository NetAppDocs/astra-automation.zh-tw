= 擷取功能
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
擷取功能，提供儲存的功能 API 資源以供檢查或整合。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/features/{feature_id}`#



[[usage-notes]]
== 使用注意事項

在 JSON 回應本文中傳回已儲存的 Feature API 資源。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| feature_id | 字串 | 路徑 | True  a| 
要列出的功能集合的 ID

|===


[[response]]
== 回應

[source]
----
Status: 200, Returns the stored Feature API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* 「application/astra-feature」




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
包含功能名稱的 JSON 字串，採用階層式點標記法。已定義的值包括：

* 最短長度：1
* 最大長度：63
* 此字串經過內部驗證，可防止 XSS、Unicode、目錄遍歷和 SQL 注入攻擊。




| isEnabled | 字串 | True  a| 
JSON 字串包含一個值，指示功能標誌是開啟還是關閉。已定義的值包括：

* 「true」- 功能旗標已啟用。
* 「false」- 功能旗標已停用。




| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構


|===

  "version": "1.1",

  }
}
----
====
