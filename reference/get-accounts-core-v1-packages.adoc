= 列出所有套件
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/packages`#

傳回集合中所有符合資源的 JSON 陣列。如果在請求中指定了個別欄位，則項目 JSON 陣列將按指定順序包含每個相符資源所請求的欄位。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 篩選器 | 字串 | 查詢 | 錯誤  a| 
指示在列出集合時，為了傳回資源而應符合哪些欄位。

支援的運算子包括：

* eq - 等式
* lt/gt - 小於/大於
* lte/gte - 小於或等於/大於或等於


URL 範例：「filter=field%20eq%20%27value%27」

OpenAPI 範例："field eq 'value'"



| 訂單者 | 字串 | 查詢 | 錯誤  a| 
指示列出集合時資源的排序順序。

URL 範例：「orderBy=name」、「orderBy=name%20desc」

OpenAPI 範例："name desc"



| 包括 | 字串 | 查詢 | 錯誤  a| 
指示列出集合時應傳回哪些欄位。

URL 範例：「include=id」、「include=id,name」

OpenAPI 範例："id"

* 範例：id、packageName、packageVersion、softwareType




| 限制 | 字串 | 查詢 | 錯誤  a| 
表示列出集合時要傳回的資源數量上限。

URL 範例：「limit=2」

OpenAPI 範例：「2」

|===
