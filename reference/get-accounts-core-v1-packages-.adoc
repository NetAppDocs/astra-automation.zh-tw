= 擷取套件
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/packages/{package_id}`#

在 JSON 回應本文中傳回已儲存的 Package API 資源。



== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| package_id | 字串 | 路徑 | True  a| 
要列出的套件集合 ID

|===


== 回應

[source]
----
Status: 200, Returns the stored Package API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-package"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| packageName | 字串 | True  a| 
包含套件名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：31 範例值如下：
* "acc"
* "acs"
* "Trident"




| packageVersion | 字串 | True  a| 
包含套件 SemVer 的 JSON 字串。已定義的值包括：

* 符合 SemVer 模式




| packageType | 字串 | True  a| 
包含套件類型的 JSON 字串，指示這是完整安裝套件還是修補程式。已定義的值包括：

* 「安裝」
* 「patch」




| bundleName | 陣列［string］ | 錯誤  a| 
包含套件所在套裝組合名稱的 JSON 字串 JSON 陣列。



| severityLevel | 字串 | True  a| 
描述此修補程式或安裝嚴重性層級的 JSON 字串。定義的值為：

* 「建議」- 建議安裝 - 預設值
* 「關鍵」 - 強烈建議安裝，以修復關鍵錯誤和 / 或安全修補程式




| packageState | 字串 | True  a| 
JSON 字串，包含指示套件運作狀態的值。套件驗證並匯入後，狀態將顯示為「complete」。否則，狀態將顯示為「incomplete」。定義的值為：

* 「正在驗證」—套件正在驗證程序中
* 「corrupt」- 套件已損毀
* 「不完整」- 套件缺少元素
* 「available」- 與該套件相關的所有元素均已可用，且該套件已準備就緒，可供使用




| packageStateTransitions | 陣列[link:#type_astra_stateTransition["type_astra_stateTransition"]] | True  a| 
JSON 物件的 JSON 陣列，每個物件代表從給定已定義狀態允許的狀態轉換集。每個 JSON 物件包含「from」和「to」欄位，其中「from」值是狀態名稱，「to」值是允許的目標狀態陣列。已定義的值為：

* 符合狀態轉換架構




| packageStateDetails | 陣列[link:#type_astra_stateDetail["type_astra_stateDetail"]] | True  a| 
JSON 物件的 JSON 陣列，其中列出有關目前「狀態」的其他詳細資料。如果沒有可用的詳細資料，此陣列將為空白。

* 最低項目數：0




| 映像 | 陣列[link:#images["映像"]] | 錯誤  a| 
JSON 陣列，包含 JSON 物件，每個物件都包含一個屬於該套件的 Docker 映像。



| 成品 | 陣列[link:#artifacts["成品"]] | 錯誤  a| 
描述與此套件相關的其他成品（二進位檔案和其他檔案）的 JSON 物件 JSON 陣列。



| 檔案 | 陣列[link:#files["檔案"]] | 錯誤  a| 
JSON 陣列，包含 JSON 物件，每個物件代表與此套件相關聯的非映像成品。



| upgradableVersions | link:#upgradableVersions["upgradableVersions"] | 錯誤  a| 
JSON 物件，包含可升級至套件版本的最低和最高版本。



| 相依性 | 陣列[link:#dependencies["相依性"]] | 錯誤  a| 
JSON 物件的 JSON 陣列，描述安裝此套件所需的指定相依性最低版本



| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra Metadata Schema。如果在建立時未指定、則會建立沒有標籤的中繼資料物件。
