= 刪除雲端
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/clouds/{cloud_id}`#

刪除所要求的雲端執行個體以及與該特定雲端相關聯的任何非託管叢集和磁碟區。



== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| cloud_id | 字串 | 路徑 | True  a| 
要列出的雲端集合 ID

|===
