= 刪除使用者
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/users/{user_id}`#

移除指定的 User API 資源。

*副作用*

* 與使用者關聯的以下資源將被刪除：notificationMarks、權杖，以及所有參照該使用者的 roleBindings。
* 對於「authProvider」為「local」的使用者，「keyType」為「passwordHash」的連結認證資料也會一併刪除。




[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| user_id | 字串 | 路徑 | True  a| 
要列出的使用者集合 ID

|===
