= 擷取應用程式的 Volume
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
為應用程式檢索 Volume，提供已儲存 Volume 資源的詳細資訊。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/volumes/{volume_id}`#



[[usage-notes]]
== 使用注意事項

在 JSON 回應本文中傳回已儲存的 Volume API 資源。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| app_id | 字串 | 路徑 | True  a| 
包含應用程式資源的 ID



| volume_id | 字串 | 路徑 | True  a| 
要列出的磁碟區集合 ID

|===


[[response]]
== 回應

[source]
----
Status: 200, Returns the stored Volume API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-volume"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
包含磁碟區名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：255




| 狀態 | 字串 | 錯誤  a| 
JSON 字串，包含指示磁碟區運作狀態的值。



| 尺寸 | 字串 | 錯誤  a| 
包含磁碟區大小的 JSON 字串。



| 已使用 | 數字 | 錯誤  a| 
包含已佈建磁碟區所用配額位元組數的 JSON 數字。



| usedPercentage | 數字 | 錯誤  a| 
包含已使用磁碟區百分比的 JSON 數字。



| 總計 | 數字 | 錯誤  a| 
包含已配置磁碟區總位元組數的 JSON 數字。



| creationToken | 字串 | 錯誤  a| 
包含磁碟區建立權杖的 JSON 字串。定義的值為：

* 最短長度：1
* 最大長度：255




| snapshotPossible | 字串 | 錯誤  a| 
指示驅動程式是否可以對磁碟區執行快照的 JSON 字串。定義的值包括：

* "true" - 驅動程式可以對磁碟區進行快照
* "false" - 驅動程式無法對磁碟區進行快照




| storageClass | 字串 | 錯誤  a| 
包含磁碟區儲存類別的 JSON 字串。

* 已定義值如下：
* 最短長度：1
* 最大長度：255




| pvcName | 字串 | 錯誤  a| 
包含磁碟區 PersistentVolumeClaim （PVC）名稱的 JSON 字串。

* 已定義值如下：
* 最短長度：1
* 最大長度：255




| internalName | 字串 | 錯誤  a| 
包含目標儲存叢集上磁碟區的內部名稱（如果可用）的 JSON 字串。此名稱從 Kubernetes CSI 驅動程式取得。

* 已定義值如下：
* 最短長度：1
* 最大長度：255




| appsUsing | 陣列［string］ | True  a| 
包含多個 JSON 字串的 JSON 陣列，每個字串包含正在使用該磁碟區的應用程式的 ID。已定義的值包括：

* 符合 Astra 識別符架構




| storageBackendID | 字串 | 錯誤  a| 
包含提供該磁碟區的儲存後端 ID 的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 協調器 | 字串 | 錯誤  a| 
包含此磁碟區協調器的 JSON 字串。此字串將為 Astra Data Store 磁碟區定義。已定義的值包括：

* 「trident」－ Trident 已配置此磁碟區
* "vasa" - NetApp VASA Provider 已配置此磁碟區
* 「其他」- 磁碟區已手動配置，或協調器未知




| serviceLevel | 字串 | 錯誤  a| 
包含儲存後端層級為此磁碟區定義的服務品質（QoS）策略的 JSON 字串。此策略將針對 Astra Data Store 磁碟區進行定義。



| exportPolicy | 字串 | 錯誤  a| 
包含與此磁碟區關聯的匯出原則的 JSON 字串。這將針對 Astra Data Store 磁碟區進行定義。



| nodeId | 字串 | 錯誤  a| 
包含磁碟區所在節點 ID 的 JSON 字串。此字串將用於 Astra Data Store 磁碟區。已定義的值包括：

* 符合 Astra 識別符架構




| healthState | 字串 | 錯誤  a| 
包含指示磁碟區健全狀態值的 JSON 字串。此字串將針對 Astra Data Store 磁碟區進行定義。已定義的值包括：

* 「不確定」- 無法判斷資源的健全狀況 （例如，由於缺乏連線能力）
* 「normal」- 資源沒有已知問題，可依據介面規格提供服務
* 「警告」- 該資源有已知問題，但這並不妨礙其依照介面規範提供服務
* 「critical」- 此資源有已知問題，導致其無法依照介面規格提供服務




| healthStateDetails | 陣列[link:#type_astra_stateDetail["type_astra_stateDetail"]] | True  a| 
包含 JSON 物件的 JSON 陣列，其中列出了有關目前健全狀況的其他詳細資訊。如果沒有可用的詳細資訊，則此陣列為空白。

* 最低項目數：0




| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構
