= 列出所有訂閱
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/subscriptions`#

傳回集合中所有符合資源的 JSON 陣列。如果在請求中指定了個別欄位，則項目 JSON 陣列將按指定順序包含每個相符資源所請求的欄位。

|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 繼續 |  | 查詢 | 錯誤  a| 
指示要從哪個權杖繼續列出。

| 數 | 字串 | 查詢 | 錯誤  a|

| 限制 | 字串 | 查詢 | 錯誤  a|

OpenAPI 範例：「2」



| 訂單者 | 字串 | 查詢 | 錯誤  a|

|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-subscription"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| customerProfileID | 字串 | True  a| 
包含客戶資料 ID 的 JSON 字串 http://authorize.net["Authorize.net"]（由 UI 呼叫）在試用期內未設定。如果未設定，則在讀取操作期間傳回空字串。已定義的值包括：

* 最短長度：0
* 最大長度：63




| paymentProfileID | 字串 | 錯誤  a| 
包含由使用者介面呼叫的 http://Authorize.net["Authorize.net"]支付設定檔 ID 的 JSON 字串，未設定為試用期。如果未設定，則在讀取操作期間傳回空字串。已定義的值包括：

* 最短長度：0
* 最大長度：63




| paymentExpiry | 字串 | 錯誤  a| 
包含時間戳記的 JSON 字串，指示付款方式的到期時間。此資訊來自 authorize.net](http://authorize.net[]，並由使用者介面設定。已定義的值包括：

* 符合 ISO-8601 日期時間架構。試用條款不會傳回此欄位。




| purchaseOrderNumber | 字串 | 錯誤  a| 
包含付款方式採購訂單號碼的 JSON 字串。定義的值為：

* 最短長度：1
* 最大長度：31




| 市集 | 字串 | 錯誤  a| 
JSON 字串，用於指示帳戶的市場，付款資訊將在該市場上記錄。定義值：

* "netapp"
* "azure"
* "aws"
* "gcp"




| licenseSN | 字串 | 錯誤  a| 
包含付款方式授權序號的 JSON 字串。定義的值為：

* 最短長度：1
* 最大長度：31




| 條款 | 字串 | True  a| 
表示帳戶目前層級的 JSON 字串。定義的值包括：

* 「trial」
* 「paid」




| 狀態 | 字串 | True  a| 
表示訂閱目前狀態的 JSON 字串。定義值包括：

* "active"
* 「inactive」




| appLimit | 數字 | True  a| 
JSON 數字表示此訂閱的應用程式限制。值為 -1 表示無限制。



| namespaceLimit | 數字 | True  a| 
JSON 數字表示此訂閱的命名空間限制。值為 -1 表示沒有限制。



| subscriptionPeriod | 數字 | True  a| 
JSON 數值，表示訂閱週期。值為 -1 表示無限制。單位：天



| gracePeriod | 數字 | True  a| 
JSON 數值，表示試用訂閱到期或付費訂閱取消後的寬限期。單位：天



| reminderBeforePeriod | 數字 | True  a| 
JSON 數字，表示試用訂閱結束前幾天開始向客戶發送通知。該值以天為單位，值為 -1 表示不適用。



| onboardStatus | 字串 | True  a| 
指示客戶註冊目前狀態的 JSON 字串。有效值為 "not started"、"in progress"、"success"、"failed"。已定義的值包括：

* 「未開始」
* 「進行中」
* 「success」
* 「失敗」




| costPerAppUnit | 數字 | True  a| 
JSON 數字表示每個應用程式單元的成本。試用版的值為 0。單位：美元



| costPerNamespaceUnit | 數字 | True  a| 
JSON 數字，表示每個命名空間單位的成本。試用版的值為 0。單位：美元



| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。
