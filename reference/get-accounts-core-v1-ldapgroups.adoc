= 列出所有 LDAP 群組
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/ldapGroups`#

傳回包含請求 URL 結果的 JSON 物件 JSON 陣列。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 包括 | 字串 | 查詢 | 錯誤  a| 
指示列出集合時應傳回哪些欄位。

URL 範例：「include=id」、「include=id,name」

OpenAPI 範例："id"

* 範例：id、cn、dn




| 限制 | 字串 | 查詢 | 錯誤  a| 
表示列出集合時要傳回的資源數量上限。

URL 範例：「limit=2」

OpenAPI 範例：「2」



| 篩選器 | 字串 | 查詢 | 錯誤  a| 
指示在列出集合時，為了傳回資源而應符合哪些欄位。

支援的運算子包括：

* eq - 等式
* lt/gt - 小於/大於
* lte/gte - 小於或等於/大於或等於


URL 範例：「filter=field%20eq%20%27value%27」

OpenAPI 範例："field eq 'value'"



| 繼續 |  | 查詢 | 錯誤  a| 
指示要從哪個權杖繼續列出。

URL 範例：「continue=+++<continue token="" from="" collection="" metadata="">+++」+++</continue>+++

OpenAPI 範例："+++<continue token="" from="" collection="" metadata="">+++"+++</continue>+++</continue>

|===
