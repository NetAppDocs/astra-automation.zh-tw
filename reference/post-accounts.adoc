= 建立新帳戶
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
建立新帳戶，並指定帳戶 API 資源所需的值。使用此功能來設置與設定存取服務的帳戶詳細資訊。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts`#



[[usage-notes]]
== 使用注意事項

指示要建立的 Account API 資源的所需值。



[[request-body]]
== 請求本文

指示要建立的 Account API 資源的所需值。

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-account"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| 姓名 | 字串 | True  a| 
包含帳戶名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63
* 此字串經過內部驗證，可防止 XSS、Unicode、目錄遍歷和 SQL 注入攻擊。




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例請求
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-account",
  "version": "1.0",
  "name": "Testing 123"
}
----
====


[[response]]
== 回應

[source]
----
Status: 201, Returns the newly created account resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-account"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
包含帳戶名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63
* 此字串經過內部驗證，可防止 XSS、Unicode、目錄遍歷和 SQL 注入攻擊。




| 狀態 | 字串 | True  a| 
JSON 字串包含指示帳戶運作狀態的值。定義的值為：

* 「 pending 」 - 只能對帳戶下的使用者和角色資源進行更改（預設值）
* 「active」- 可以對帳戶下的任何資源進行變更
* "deletePending" - 使用者無法登入、資料保護作業已暫停、不再產生費用




| isEnabled | 字串 | True  a| 
指示帳戶已啟用的 JSON 字串。定義的值為：

* "false" - 不允許使用者使用此帳戶
* "true" - 允許使用者使用此帳戶




| enabledTimestamp | 字串 | 錯誤  a| 
包含時間戳記的 JSON 字串，指示帳戶上次啟用的時間。如果帳戶從未啟用過，則此欄位不存在。定義的值為：

* 符合 ISO-8601 日期時間架構




| accountContact | link:#accountContact["accountContact"] | 錯誤  a| 
包含使用者聯絡資訊的 JSON 物件，用於在帳戶啟動時建立擁有者使用者。



| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例回應
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-account",
  "version": "1.0",
  "id": "666a3f38-d4fa-5b62-a391-a69029758d32",
  "name": "fraught-pines",
  "state": "pending",
  "isEnabled": "false",
  "enabledTimestamp": "2020-08-06T12:24:52.256624Z",
  "metadata": {
    "labels": [],
    "creationTimestamp": "2022-10-06T20:58:16.305662Z",
    "modificationTimestamp": "2022-10-06T20:58:16.305662Z",
    "createdBy": "8f84cf09-8036-51e4-b579-bd30cb07b269"
  }
}
----
====

[[postalAddress]]
[role="api-collapsible-fifth-title"]
postalAddress

包含一組 JSON 字串的 JSON 物件，用於指定位址。如果此金鑰不存在，則表示尚未提供位址。如果此金鑰存在，則包含的所有六個 JSON 字串都將存在。如果未提供任何內容，則字串為空。

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| addressCountry | 字串 | True  a| 
包含與郵政地址關聯的國家/地區名稱或國家/地區代碼的 JSON 字串，如 ISO 3166 Alpha-2 中所指定。定義的值為：

* 最短長度：2
* 最大長度：2




| addressLocality | 字串 | True  a| 
包含與郵寄地址相關聯的地區（例如城市）的 JSON 字串。定義的值為：

* 最短長度：1
* 最大長度：63




| addressRegion | 字串 | True  a| 
包含與郵寄地址關聯的區域（例如，州/省）的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63




| postalCode | 字串 | True  a| 
包含與郵遞地址相關聯之郵遞區號的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：31




| streetAddress1 | 字串 | True  a| 
包含與郵寄地址相關聯之街道地址的 JSON 字串。定義的值為：

* 最短長度：1
* 最大長度：63




| streetAddress2 | 字串 | 錯誤  a| 
包含選用輔助街道地址資訊、郵政信箱等的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63
