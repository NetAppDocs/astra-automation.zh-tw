= 刪除使用者的群組
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
刪除使用者的所屬群組，移除指定的群組 API 資源。關聯資源（例如引用該群組的角色綁定）也會被刪除。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/users/{user_id}/groups/{group_id}`#



[[usage-notes]]
== 使用注意事項

移除指定的 Group API 資源。

*副作用*

* 與該群組相關的以下資源會被刪除：
* 參照該群組的角色繫結




[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| user_id | 字串 | 路徑 | True  a| 
包含使用者資源的 ID



| 群組 ID | 字串 | 路徑 | True  a| 
要列出的群組集合 ID

|===
