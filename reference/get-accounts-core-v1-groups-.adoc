= 擷取群組
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}`#

在 JSON 回應本文中傳回已儲存的 Group API 資源。



== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 群組 ID | 字串 | 路徑 | True  a| 
要列出的群組集合 ID

|===


== 回應

[source]
----
Status: 200, Returns the stored Group API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* 「application/astra-group」




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
群組資源的名稱。如果在建立時未指定，則該值將設定為

* 如果在 authID 中找到，則為第一個通用名稱（CN）相對專有名稱（RDN），
* 否則為 authID。如果在更新時未指定，則該值將保留而不進行修改。定義的值為：
* 最短長度：1
* 最大長度：2048




| authProvider | 字串 | True  a| 
群組資源的驗證提供者。定義的值為：

* "ldap"




| authID | 字串 | True  a| 
LDAP 群組的辨別名稱（DN）。定義的值為：

* 最短長度：1
* 最大長度：2048




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例回應
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-group",
  "version": "1.1",
  "id": "77754011-b93f-515e-a145-5a343aecdece",
  "name": "engineering-group",
  "authProvider": "ldap",
  "authID": "CN=Engineering,CN=groups,DC=example,DC=com",
  "metadata": {
    "labels": [],
    "creationTimestamp": "2022-10-06T20:58:16.305662Z",
    "modificationTimestamp": "2022-10-06T20:58:16.305662Z",
    "createdBy": "8f84cf09-8036-51e4-b579-bd30cb07b269"
  }
}
----
====
