= 擷取未讀通知
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/users/{user_id}/unreadNotifications/{unreadNotification_id}`#

在 JSON 回應本文中傳回已儲存的未讀通知 API 資源。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| user_id | 字串 | 路徑 | True  a| 
包含使用者資源的 ID



| 未讀通知_id | 字串 | 路徑 | True  a| 
要列出的 unreadNotification 集合的 ID

|===


[[response]]
== 回應

[source]
----
Status: 200, Returns the stored Unread Notification API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-unreadNotification"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| notificationID | 字串 | True  a| 
包含通知 ID 的 JSON 字串，該 ID 將被建立標記的使用者標記為已讀取。已定義的值包括：

* 符合 Astra 識別符架構




| sequenceCount | 數字 | True  a| 
JSON 數字，包含與通知 ID 所指定通知相關聯的序列計數。



| 嚴重性 | 字串 | True  a| 
包含以下值之一的 JSON 字串，用於指示事件的嚴重程度。已定義的值包括：

* 「已清除」- 表示先前報告的描述某種狀況的事件已不再處於活動狀態。嚴重等級為「已清除」的事件將使用相同的摘要和關聯 ID，以便進行配對。
* 「不確定」—表示無法確定嚴重程度
* 「informational」- 表示狀態發生了預期且正常的改變（未在 X.733 中定義）
* 「警告」- 表示在感受到任何重大影響之前，已偵測到可能或即將發生的、影響服務的故障
* 「critical」- 表示已發生影響服務的情況，需要立即採取修正措施




| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構
