= 列出所有執行掛鉤
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
擷取所有執行掛鉤，提供符合指定條件的資源 JSON 陣列。使用此功能來檢視集合中每個掛鉤的詳細資訊。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/executionHooks`#



[[usage-notes]]
== 使用注意事項

傳回集合中所有符合資源的 JSON 陣列。如果在請求中指定了個別欄位，則項目 JSON 陣列將按指定順序包含每個相符資源所請求的欄位。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 包括 | 字串 | 查詢 | 錯誤  a| 
指示列出集合時應傳回哪些欄位。

URL 範例：「include=id」、「include=id,name」

OpenAPI 範例："id"



| 限制 | 字串 | 查詢 | 錯誤  a| 
表示列出集合時要傳回的資源數量上限。

URL 範例：「limit=2」

OpenAPI 範例：「2」



| 篩選器 | 字串 | 查詢 | 錯誤  a| 
指示在列出集合時，為了傳回資源而應符合哪些欄位。

支援的運算子包括：

* eq - 等式
* lt/gt - 小於/大於
* lte/gte - 小於或等於/大於或等於


URL 範例：「filter=field%20eq%20%27value%27」

OpenAPI 範例："field eq 'value'"

|===

[[executionHook_1_3_get_response_body]]
[role="api-collapsible-fifth-title"]
executionHook_1.3_get_response_body

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-executionHook"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"
* "1.2"
* "1.3"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
包含使用者指定資源名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63 名稱在所有執行掛鉤資源中必須是唯一的。




| hookType | 字串 | True  a| 
定義勾點類型的 JSON 字串。定義的值包括：

* "netapp" - NetApp 提供的執行鉤子。
* 「custom」- 與特定的應用程式 ID 綁定。具有 hookType 「netapp」的執行鉤子資源為唯讀。




| matchingCriteria | 陣列[link:#matchingCriteria["matchingCriteria"]] | True  a| 
描述執行鉤子匹配條件的 JSON 物件 JSON 陣列。當指定多個 matchingCriteria 時，會對條件套用邏輯 AND。定義的值為：

* 最少項目數：0
* 最多項目數：10




| matchingContainers | 陣列[link:#matchingContainers["matchingContainers"]] | 錯誤  a| 
JSON 陣列，其中包含定義應用程式中符合已設定比對條件的每個容器的 JSON 物件。



| matchingImages | 陣列［string］ | 錯誤  a| 
符合容器映像的 JSON 字串 JSON 陣列。定義的值為：

* 最少項目數：0
* 項目上限：4095
* 最短長度：1
* 最大長度：255




| 動作 | 字串 | True  a| 
JSON 字串，指示在符合條件的情況下，執行掛鉤將執行哪個動作。定義的值為：

* 「Snapshot」
* 「備份」
* 「還原」
* 「容錯移轉」




| 階段 | 字串 | True  a| 
JSON 字串，指示掛鉤將在動作的哪個階段執行。已定義的值包括：

* "pre" - 執行鉤子將在指定操作之前執行。
* "post" - 執行掛鉤將在指定動作之後執行。動作 "snapshot" 的值為 "pre" 和 "post"。動作 "backup" 的值為 "pre" 和 "post"。動作 "restore" 的值為 "post"。動作 "failover" 的值為 "post"。




| hookSourceID | 字串 | True  a| 
包含透過此執行掛鉤執行的掛鉤來源 ID 的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 引數 | 陣列［string］ | 錯誤  a| 
來源引數的 JSON 字串 JSON 陣列。定義的值為：

* 最少項目數：0
* 項目上限：16
* 最短長度：0
* 最大長度：127




| appID | 字串 | 錯誤  a| 
包含此鉤子所關聯應用程式 ID 的 JSON 字串。本質上，其他匹配條件（如果已設定）。已定義的值包括：

* 符合 Astra 識別符架構




| 已啟用 | 字串 | True  a| 
指示執行掛鉤是否已啟用的 JSON 字串。已定義的值包括：

* "true" - 執行鉤子已啟用，並將按指定方式執行。
* 「false」－執行鉤子已停用，永遠無法運作。預設值為「true」。




| 描述 | 字串 | 錯誤  a| 
包含使用者指定的 hook 來源描述的 JSON 字串。已定義的值包括：

* 最短長度：0
* 最大長度：511




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。
