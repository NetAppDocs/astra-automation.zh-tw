= 從應用程式備份中擷取應用程式資產
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/appBackups/{appBackup_id}/appAssets/{appAsset_id}`#

在 JSON 回應正文中傳回已儲存的應用程式資產 API 資源。



== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| appBackup_id | 字串 | 路徑 | True  a| 
包含 appBackup 資源的 ID



| appAsset_id | 字串 | 路徑 | True  a| 
要列出的 appAsset 集合的 ID

|===


== 回應

[source]
----
Status: 200, Returns the stored Application Asset API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-appAsset"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| assetType | 字串 | True  a| 
JSON 字串，包含一個值，指示從 Kubernetes 取得的所描述資產類型。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 建立時間戳記 | 字串 | True  a| 
包含時間戳記的 JSON 字串，指示 Kubernetes 元資料的建立時間。已定義的值包括：

* 符合 ISO-8601 日期時間架構




| GVK | link:#GVK["GVK"] | True  a| 
包含 Kubernetes 群組 / 版本 / 類型的 JSON 物件。



| 資源 | link:#type_json["type_json"] | 錯誤  a| 
包含 Kubernetes 資源定義全部內容的 JSON 物件。



| assetID | 字串 | True  a| 
包含 Kubernetes 指派的識別碼的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| 標籤 | 陣列[link:#labels["標籤"]] | True  a| 
JSON 物件的 JSON 陣列，每個物件都包含與該資產關聯的 Kubernetes 標籤。如果沒有可用的詳細資訊，則此陣列為空。

* 最少項目數：0




| assetName | 字串 | True  a| 
包含 Kubernetes 指派的名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 命名空間 | 字串 | 錯誤  a| 
包含 Kubernetes 指派的命名空間的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構
