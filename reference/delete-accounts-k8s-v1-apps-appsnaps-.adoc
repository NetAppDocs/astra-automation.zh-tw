= 刪除應用程式快照
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/appSnaps/{appSnap_id}`#

移除指定的 Application Snapshot API 資源。

*副作用*

* 如果快照正在進行中，則會取消快照。
* 如果快照已完成，則快照資料將被刪除。




[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| app_id | 字串 | 路徑 | True  a| 
包含應用程式資源的 ID



| appSnap_id | 字串 | 路徑 | True  a| 
要列出的 appSnap 集合的 ID

|===

== 回應

[source]

Status: 204, Indicates if the appSnap resource was deleted.
