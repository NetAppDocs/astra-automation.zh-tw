= 建立新的 AppMirror 資源
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/appMirrors`#

指示要建立的 AppMirror API 資源的所需值。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}


|===


[[request-body]]
== 請求本文

指示要建立的 AppMirror API 資源的所需值。

[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-appMirror"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"




| 來源應用程式 ID | 字串 | True  a| 
來源應用程式的識別碼。僅在將 sourceAppID 與 destinationAppID 互換時更新。定義的值為：

* 符合 Astra 識別符架構




| 目的地叢集 ID | 字串 | True  a| 
用於託管目標應用程式的受管叢集識別碼。建立時必須提供，因為它決定了目標應用程式將在哪個叢集上建立。如果在更新時提供，則它必須與目標應用程式的叢集 ID 相符，因此只有在 sourceAppID 與 destinationAppID 互換時才會變更。定義的值為：

* 符合 Astra 識別符架構




| namespaceMapping | 陣列[link:#namespaceMapping["namespaceMapping"]] | 錯誤  a| 
建立目標應用程式時要使用的命名空間，與來源應用程式的命名空間相對應。每個 JSON 物件包含「clusterID」和「namespaces」欄位，其中「clusterID」的值是來源叢集或目標叢集的 JSON 字串 ID，「namespaces」的值是 JSON 字串陣列。每個叢集必須只有一個 JSON 物件，命名空間將透過索引關聯。如果未提供，則目標叢集將使用與來源叢集相同的命名空間。已定義的值如下：

* 最短長度：0
* 最大長度：2




| storageClasses | 陣列[link:#storageClasses["storageClasses"]] | 錯誤  a| 
建立新的持久性磁碟區宣告（PVC）時，目標叢集上要使用的儲存類別。每個 JSON 物件包含欄位 "clusterID" 和 "storageClassName"，其中 "clusterID" 的值是來源叢集或目標叢集的 JSON 字串 ID，"storageClassName" 是在該叢集上建立 PVC 時要使用的儲存類別。如果未提供或某個叢集缺少該值，則將使用該叢集的預設儲存類別。已定義的值包括：

* 最短長度：0
* 最大長度：2




| stateDesired | 字串 | True  a| 
關係的理想狀態。建立時，唯一有效值為 "established"。已定義的值包括：

* 「established」- 關係已建立。
* "failedOver" - 應用程式故障轉移到目標叢集已完成。
* 「已刪除」- 該關係已成功清理並刪除。




| 中繼資料 | link:#type_astra_metadata_update["type_astra_metadata_update"] | 錯誤  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 遵循 Astra Metadata Schema。如果在建立時未指定，則建立的元資料物件將不帶任何標籤。如果在更新時未指定，元資料物件的標籤、creationTimestamp 和 createdBy 將保持不變。


|===
.範例請求
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-appMirror",
  "version": "1.1",
  "sourceAppID": "efd639b6-fc92-4112-8841-0c0ab7890ae0",
  "destinationClusterID": "c5d023a9-4061-4a8a-bfbf-3be11ff06226",
  "stateDesired": "established"
}
----
====
