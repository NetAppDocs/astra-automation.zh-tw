= 擷取任務
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/tasks/{task_id}`#

在 JSON 回應本文中傳回已儲存的 Task API 資源。



== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| task_id | 字串 | 路徑 | True  a| 
要列出的任務集合 ID

|===


== 回應

[source]
----
Status: 200, Returns the stored Task API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "application/astra-task"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"
* "1.1"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
包含任務點標記法 (.) 階層名稱的 JSON 字串。已定義的值包括：

* 最短長度：3
* 最大長度：127
* 定義的正規表示式為："^(([a-z])_(\.))_([a-z])+$"




| 摘要 | 字串 | True  a| 
包含任務簡短摘要的 JSON 字串。定義的值為：

* 最短長度：3
* 最大長度：63




| 描述 | 字串 | True  a| 
包含任務說明的 JSON 字串。定義的值為：

* 最短長度：1
* 最大長度：511




| 服務 | 字串 | 錯誤  a| 
包含管理工作的服務名稱的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：31




| parentTaskID | 字串 | 錯誤  a| 
包含任務父任務全域唯一識別碼的 JSON 字串。已定義的值包括：

* 符合 Astra 識別符架構




| userID | 字串 | 錯誤  a| 
包含與任務相關聯之使用者 ID 的 JSON 字串。僅包含與使用者啟動之動作相關聯的任務。定義的值為：

* 符合 Astra 識別符架構




| resourceID | 字串 | True  a| 
JSON 字串，包含與任務關聯的資源的全域唯一識別碼。已定義的值包括：

* 符合 Astra 識別符架構




| resourceURI | 字串 | True  a| 
包含與任務相關聯之 URI 的 JSON 字串。已定義的值為：

* 最短長度：3
* 最大長度：4095




| resourceCollectionURI | 陣列［string］ | True  a| 
JSON 字串的 JSON 陣列，每個字串表示與任務相關聯之資源的完整展開存取 URL。已定義的值為：

* 最短長度：3
* 最大長度：4095




| 狀態 | 字串 | True  a| 
包含指示任務運作狀態的值的 JSON 字串。已定義的值包括：

* 「notStarted」- 任務尚未開始執行。
* 「running」- 工作正在執行中。
* 「completed」- 工作已完成。
* 「暫停」- 該任務被請求暫停。
* 「已暫停」- 任務已暫停。
* 「取消」- 該任務被要求取消。
* 「cancelled」- 任務已取消。
* 「failed」——任務失敗。
* 最短長度：1
* 最大長度：31




| stateTransitions | 陣列[link:#type_astra_stateTransition["type_astra_stateTransition"]] | True  a| 
JSON 物件的 JSON 陣列，每個物件代表從給定已定義狀態出發的允許狀態轉換集。每個 JSON 物件包含「from」和「to」欄位，其中「from」值是狀態名稱，「to」值是允許的目標狀態陣列。

* 最短長度：1
* 最大長度：31 例如："stateTransitions" : [ { "from": "running", "to": ["paused", "cancelled"] }, { "from": "paused", "to": ["running", "cancelled"] }, ]




| stateDetails | 陣列[link:#type_astra_stateDetail["type_astra_stateDetail"]] | True  a| 
包含 JSON 物件的 JSON 陣列，其中列出了有關目前「狀態」的其他詳細資訊。此欄位指示是否存在阻止實際狀態與預期狀態相符的條件或錯誤。如果沒有可用的詳細資訊，則此陣列為空白。

* 最低項目數：0




| orderHint | 數字 | 錯誤  a| 
表示子任務順序的 JSON 數字。客戶端可以使用此欄位按從小到大的順序對子任務進行排序。



| percentDone | 數字 | 錯誤  a| 
包含正在執行的任務完成百分比的 JSON 數字。任務完成後，此值將設定為 "100"。



| startTime | 字串 | 錯誤  a| 
包含指示任務開始時間戳記的 JSON 字串。定義的值為：

* 符合 ISO-8601 日期時間架構




| endTime | 字串 | 錯誤  a| 
包含任務結束時間戳記的 JSON 字串。定義的值為：

* 符合 ISO-8601 日期時間架構




| cancelTime | 字串 | 錯誤  a| 
包含指示任務取消時間戳記的 JSON 字串。定義的值為：

* 符合 ISO-8601 日期時間架構




| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構
