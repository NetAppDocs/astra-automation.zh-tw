= 列出應用程式備份的應用程式資產
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
擷取應用程式備份的應用程式資產，並提供集合中所有相符資源的 JSON 陣列。使用此功能可依指定順序檢視每個資源的特定欄位。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/appBackups/{appBackup_id}/appAssets`#



[[usage-notes]]
== 使用注意事項

傳回集合中所有符合資源的 JSON 陣列。如果在請求中指定了個別欄位，則項目 JSON 陣列將按指定順序包含每個相符資源所請求的欄位。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| appBackup_id | 字串 | 路徑 | True  a| 
包含 appBackup 資源的 ID



| 包括 | 字串 | 查詢 | 錯誤  a| 
指示列出集合時應傳回哪些欄位。

URL 範例：「include=id」、「include=id,name」

OpenAPI 範例："id"

* 例如： assetType、assetName




| 限制 | 字串 | 查詢 | 錯誤  a| 
表示列出集合時要傳回的資源數量上限。

URL 範例：「limit=2」

OpenAPI 範例：「2」

|===
