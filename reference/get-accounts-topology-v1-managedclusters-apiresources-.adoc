= 擷取 K8s API 資源
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/managedClusters/{managedCluster_id}/apiResources/{apiResource_id}`#

在 JSON 回應本文中傳回特定的 API 資源。



== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| managedCluster_id | 字串 | 路徑 | True  a| 
包含 managedCluster 資源的 ID



| apiResource_id | 字串 | 路徑 | True  a| 
要列出的 apiResource 集合的 ID

|===


== 回應

[source]
----
Status: 200, Returns the specific API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-apiResource"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| apiVersion | 字串 | True  a| 
表示資源 API 版本的 JSON 字串，該版本由 Kubernetes 設定或透過 Kubernetes 設定。APIVersion 定義了此物件表示的版本化模式。伺服器應將已識別的模式轉換為最新的內部值，並可能拒絕無法識別的值。更多資訊： https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#resources[]



| 種類 | 字串 | True  a| 
表示資源類型的 JSON 字串，由 Kubernetes 設定或透過 Kubernetes 設定。`kind` 欄位使用駝峰命名法，包含一個字串值，表示此物件所代表的 REST 資源。伺服器可能會根據客戶端提交請求的端點推斷出此資訊。此欄位無法更新。更多資訊： https://git.k8s.io/community/contributors/devel/sig-architecture/api-conventions.md#types-kinds[]



| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構


|===
