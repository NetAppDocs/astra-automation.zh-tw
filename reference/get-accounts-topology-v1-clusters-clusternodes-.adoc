= 為叢集擷取叢集節點
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
檢索叢集的叢集節點，提供有關該節點在指定叢集中的組態和狀態的詳細資訊。



[[http-method-and-endpoint]]
== HTTP 方法和端點

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/clusters/{cluster_id}/clusterNodes/{clusterNode_id}`#



[[usage-notes]]
== 使用注意事項

在 JSON 回應本文中傳回已儲存的叢集節點 API 資源。



[[parameters]]
== 參數

[cols="5*"]
|===
| Name | 類型 | 在 | 必要 | 說明 


| account_id | 字串 | 路徑 | True  a| 
包含帳戶資源的 ID

* 範例：{{.Account}}




| 叢集 ID | 字串 | 路徑 | True  a| 
包含叢集資源的 ID



| clusterNode_id | 字串 | 路徑 | True  a| 
要列出的 clusterNode 集合的 ID

|===


[[response]]
== 回應

[source]
----
Status: 200, Returns the stored Cluster Node API resource in the JSON response body.
----
[cols="4*"]
|===
| Name | 類型 | 必要 | 說明 


| 類型 | 字串 | True  a| 
資源的媒體類型。定義的值為：

* "應用程式/astra-clusterNode"




| 版本 | 字串 | True  a| 
資源版本。已定義值包括：

* "1.0"




| ID | 字串 | True  a| 
資源的全域唯一識別碼。定義的值為：

* 符合 UUIDv4 架構




| 姓名 | 字串 | True  a| 
包含節點 Kubernetes 名稱值的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 角色 | 字串 | True  a| 
包含節點 Kubernetes 角色值的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 標籤 | 陣列[link:#labels["標籤"]] | True  a| 
JSON 物件的 JSON 陣列，每個物件都包含與節點關聯的 Kubernetes 標籤。如果沒有可用的詳細資訊，此陣列將為空白。

* 最少項目數：0




| creationTime | 字串 | True  a| 
包含 ISO 8601 時間戳記的 JSON 字串，用於指示節點的建立時間。已定義的值包括：

* 符合 ISO-8601 日期時間架構




| externalIP | 字串 | True  a| 
包含節點內部 IP 位址值的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63




| internalIP | 字串 | True  a| 
包含節點外部 IP 位址值的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：63




| 區域 | 字串 | True  a| 
包含節點 Kubernetes 區域值的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 區域 | 字串 | True  a| 
包含節點 Kubernetes 區域值的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：254




| instanceType | 字串 | True  a| 
JSON 字串包含一個值，該值指示節點的 Kubernetes 執行個體類型。已定義的值包括：

* 最短長度：1
* 最大長度：254




| kernelVersion | 字串 | True  a| 
JSON 字串，包含指出節點所使用核心版本的值。定義的值包括：

* 最短長度：1
* 最大長度：254




| osImage | 字串 | True  a| 
包含節點所用作業系統映像值的 JSON 字串。已定義的值包括：

* 最短長度：1
* 最大長度：254




| numCpus | 字串 | True  a| 
JSON 字串包含一個值，該值指示指派給節點的 CPU 數量。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 記憶體 | 字串 | True  a| 
JSON 字串包含一個值，該值指示分配給節點的記憶體量。已定義的值包括：

* 最短長度：1
* 最大長度：254




| 狀態 | 字串 | True  a| 
包含指示節點運作狀態值的 JSON 字串。定義的值為：

* 「running」— 節點運作正常
* 「provisioning」—節點正在配置過程中
* 「discovering」- 節點的各個面向正在被發現的過程中
* 「pending」- 節點已排程進行探索
* 「失敗」- 節點處於故障狀態
* 「未知」- 無法確定節點的狀態




| 中繼資料 | link:#type_astra_metadata["type_astra_metadata"] | True  a| 
與資源相關聯的用戶端和服務指定中繼資料。定義的值為：

* 符合 Astra 中繼資料架構
